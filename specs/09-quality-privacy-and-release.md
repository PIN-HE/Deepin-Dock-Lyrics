# S09 测试、隐私与发布

**状态：** 待实施

**前置：** S00-S08
**后续：** MVP 发布

## 目标

建立覆盖核心行为、桌面集成、服务条款和用户隐私的发布门禁，使 `deepin-dock-lyrics` 能以 MIT 开源小工具的方式发布，而不对歌词覆盖率或逐字能力做无法兑现的承诺。

## 范围

- 建立单元、集成、安装和手工视觉测试矩阵。
- 建立 CI：格式/静态检查、构建、CTest、Debian 构建与包内容检查。
- 发布前审查 LRCLIB 最新文档、调用规则、速率限制、署名要求和服务条款。
- 提供 README 隐私说明、已知限制、故障排查和缺陷报告模板。

## 非范围

- 不把 CI 结果作为对所有播放器、所有音乐或所有主题组合的绝对兼容性承诺。
- 不采集用户行为、歌曲历史、日志回传或崩溃遥测。

## 自动测试层次

| 层 | 目标 | 必测内容 |
|---|---|---|
| 单元 | `lyrics-core` | 文本规范化、候选评分、LRC 解析、位置到帧的计算 |
| 单元 | LRCLIB client | URL 参数、User-Agent、串行队列、429、缓存 TTL、负缓存 |
| 集成 | fake MPRIS + daemon | 发现、玩家切换、暂停、拖动、切歌、D-Bus 状态机 |
| 集成 | fake D-Bus + Applet bridge | 断线重连、初始 `GetState`、帧节流、会话隐藏 |
| 安装 | `.deb` | 文件路径、依赖、D-Bus 激活、用户服务、升级/卸载 |
| 视觉 | 真 `dde-shell` 会话 | 四边 Dock、亮暗主题、不同尺寸、长文本、RTL |

网络测试必须通过 fixture/fake transport 完成，不能在 CI 依赖真实 LRCLIB 可用性或消耗其公共服务配额。

## 手工验收矩阵

| 场景 | 预期 |
|---|---|
| 一个 MPRIS 播放器播放/暂停/拖动 | 当前行在 250 ms 内正确变化，暂停不自行前进 |
| 两个 MPRIS 播放器 | 仅用户选定播放器驱动歌词 |
| 空元数据、直播流、纯音乐 | 不联网或显示无歌词，无崩溃 |
| 有 LRC、仅 plain lyrics、无歌词 | 分别显示逐行、非同步、无歌词状态 |
| 匹配歧义 | 不自动采用低分候选，设置页可手动确认 |
| 离线、5xx、429 | 可理解的状态、遵守退避、不忙循环 |
| Dock 四边 / 多显示器 / 亮暗主题 | 不重叠、居中、可读、关闭按钮可点击 |
| 注销登录、升级、卸载 | 配置持久化符合 S08，服务不残留 |

## 发布文案的硬性要求

- 明示“仅支持 Linux 原生 MPRIS 播放器；Wine/Windows 播放器暂不支持”。
- 明示“歌词检索仅使用 LRCLIB，并会发送必要的歌曲元数据”。
- 明示“LRC 为逐行同步；行内进度是视觉效果，不是逐字时间戳”。
- 明示“并非所有歌曲均可在 LRCLIB 找到歌词”。
- 不出现网易云音乐 API、平台登录、官方合作或版权授权的暗示。

## 发布门禁

1. 所有 CTest、静态检查和包构建通过；未跳过任何高风险用例。
2. S08 的全新安装、升级与卸载在目标环境验证通过。
3. 在发布当天复查 LRCLIB 文档与条款；任何要求变化必须先更新客户端、隐私文案或停止发布。
4. `LICENSE`、Debian copyright、README、隐私说明与实际网络行为一致，许可证为 MIT。
5. 以真实 `dde-shell` 会话完成视觉验收并记录截图，确认 Dock 不与托盘和时钟重叠。
